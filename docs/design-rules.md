# 鸣依阁 · 设计规则（硬性禁令）

> 本文件是项目唯一的设计约束来源，随仓库走。任何 UI 产出（主页、卡片、按钮、边框、背景、图标）先过下面的禁令清单（持续补充），再谈美感。

## 严格禁止（2026-11-07 定，持续补充）

1. **荧光系列**——荧光色文字、图标、按钮用色；亮荧光感的 UI 用色同样禁止
2. **辉光系列**——text-shadow 发光等任何"亮起来"的效果
3. **光晕系列**——halo、box-shadow 光圈、环境光晕
4. **色彩混合渐变系列**——color-mix 渐变、多色渐变过渡
5. **AI 味道的边框与背景系列**——渐变描边、玻璃拟态、半透明浮层芯片底、悬浮小圆片等 AI 生成风俗套
6. **弧形**——大圆角胶囊/弧形按钮与容器（`border-radius: 999px` 一类）
7. **控件的背景填充**——按钮/标签的背景样式**全部禁止**：实色底、半透明底、描边底、胶囊底一律不行；按钮只能是浮在页面上的纯文字/图标
8. **任何 emoji**——界面文案、图标、favicon 全部不用；♪ ★ ↺ 等装饰符号也不用；图标只用纯色几何 SVG
9. **环形涟漪扩散**——同心圆环从中心向外扩散/呼吸的装饰效果一律禁止（2026-11-07 补充）

**唯一例外**：入场动画的文字光效是对素材图（`docs/materials/` 图2/图3 发光手写体）的忠实还原，不属于设计发挥；入场动画保持素材本身的纯青色，不使用多巴胺配色。

## 控件写法规范

- 按钮/标签 = 纯文字（可配纯色几何 SVG 图标）+ **无背景 + 无边框 + 无圆角**
- 强调态只允许：文字亮度变化、波浪线/直线等文本装饰
- 需要容器感时：直角 + 1px 直线描边，禁止弧形
- 点缀色只用于版面上的扁平实色色块（构成用途），不用于控件

## 多巴胺风格（暂定方向，仅用于进入主页后的界面）

- 入场动画三图期间不使用多巴胺配色，保持素材的深夜纯青氛围
- 多巴胺感来自**实色色块与平面对比**，不来自发光/渐变
- 亮色主题 token 在 `src/components/site/SiteChrome.module.css` 的 `.page`；品牌点缀蓝 `#66ccff`（#6cf）用于光标、文字选中与扁平色块

## 已知实现注意

- Vite `server.watch.ignored` 必须排除 `.mimosa/`（Windows 下文件锁会导致 watcher EBUSY 崩溃）
- 入场舞台比例锁定为海报原始比例（横屏 4096×2066、竖屏 2264×4096，CSS 变量 `--stage-w/--stage-h`）；海报 `cover` 满铺画幅，画幅外用图片自身磨砂延展补边，禁止暴露纯黑
